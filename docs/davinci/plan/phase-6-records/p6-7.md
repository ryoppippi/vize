# P6-7 — JavaScript plugin SDK acceptance package

The production implementation and executable witnesses are assembled here.
The gate requires the exact integrated head's TS-51 Actions run, including real
Docker execution, before this record can mark GA accepted. A local Docker daemon
is unavailable; this is recorded as unverified local isolation, not a skipped CI
acceptance check. The release owner publishes after integrated checks pass.

## Production routes

- Public author package: `npm/plugin-sdk`, root exports and `./fixes` and
  `./sandbox` subpaths, complete declarations and optional native peer >=0.429.0.
- Rules and UTF-8 autofixes: native S2 visit records, static demands, host-owned
  spans, immutable author contexts, strict report decoding, atomic fix application.
- Facts: existing Croquis primary producers plus the producer's six versioned
  component interface pages. Unknowns, exact type strings and dependency
  completeness survive serialization. No private semantic classifier is copied.
- Custom providers: [provider contract](./p6-7-fact-providers.md), actual native
  closure scheduling, audited rows and transitive dependency stamps in rule keys.
- Transform: [native S2 contract](./p6-7-native-transform.md), typed existing static
  HTML attribute edits before canonical emission, source-map parity and atomic
  refusals. General AST mutations are outside this bounded public contract.
- Formatter/output: [compiled output contract](./p6-7-output-hooks.md), real
  compiler results, semantic formatting validation and existing map-anchor rebasing.
- Untrusted execution: explicit Docker callback-source mode, no host mounts or
  environment/network, nonroot/read-only root, dropped capabilities, resource
  limits, deadline, bounded messages and confirmed cleanup. Ordinary callbacks
  retain their documented trusted status. No automatic trust downgrade exists.

All four families have host costs and bounded content-key caches. Persistent
entries use bounded reads, schema/key validation and atomic writes. Provider
results, typed transform edits and output operations are validated again before
cache reuse. Rule cache entries revalidate exact host node spans and UTF-16
positions. Failed or nondeterministic responses are never cached.

The workflow `davinci-plugin-sdk.yml` builds the actual native binding, explicitly
pulls the pinned Docker image and executes these witnesses. Full `Check`
`test-scripts` also prepares that runtime; there is no sandbox skip condition.
Package staging, smoke, versioning and publication automation include the SDK.
